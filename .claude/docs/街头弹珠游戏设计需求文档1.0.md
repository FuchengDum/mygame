这是一个非常关键的时刻。我们将之前所有零散的讨论（操作手感、玩法规则、美术风格）统合为一份结构严谨的**游戏设计需求文档 (Game Design Document - GDD)**。

这份文档将作为开发团队（程序、美术、策划）的行动纲领，明确界定**“现在做什么（MVP）”**与**“未来做什么（Roadmap）”**。

# 项目代号：街头弹珠 (Project: Marble Street)
## 游戏设计需求文档 (v1.0)

### 1. 项目愿景 (Vision)
打造一款**极致拟真**的怀旧弹珠手游。核心卖点在于**“触感视觉化”的操作体验**和**微缩摄影级的美术表现**，还原 80/90 年代街头童年竞技的紧张感与沉浸感。

---

### 2. 开发路线图 (Development Roadmap)

为了确保项目可落地并快速验证核心乐趣，我们将需求划分为两个阶段：

#### 🔴 第一阶段：MVP 核心验证版 (当前开发目标)
*   **核心目标**：跑通物理碰撞，确立美术标杆，验证“手势拉弓”的手感。
*   **操作**：基于屏幕触控的模拟手势（骨骼动画绑定触控向量）。
*   **玩法**：单人/本地双人“街头霸王（相扑）”模式。
*   **地图**：标准平整泥土地，无复杂地形干扰。

#### 🔵 第二阶段：完整商业版 (后续迭代需求)
*   **核心目标**：丰富内容深度，增加社交与成长要素，引入前沿交互技术。
*   **操作**：引入 AI 摄像头手势识别（Full Hand Tracking）。
*   **玩法**：增加“进洞为王（老虎洞）”模式、赌注系统。
*   **地图**：复杂地形（泥坑、下水道、路牙子）。

---

### 3. 详细需求规格说明

#### A. 核心操作与物理系统 (Controls & Physics)

| 功能模块 | MVP 阶段需求 | 后续迭代需求 (Phase 2) |
| :--- | :--- | :--- |
| **手势输入** | **触控模拟**：单指拖拽屏幕模拟“拉弓”。<br>- 手指后拉距离 = 力度。<br>- 手指左右偏移 = 角度。<br>- **视觉反馈**：屏幕上的 3D 虚拟手模型根据拖拽实时产生骨骼形变（大拇指关节弯曲、指尖充血变红、皮肤褶皱堆积）。 | **AI 视觉捕捉**：<br>调用手机前置/后置摄像头，识别玩家真实手势。<br>玩家在空中做弹球动作，游戏内同步映射。 |
| **物理反馈** | **基础碰撞**：<br>- 刚体碰撞（弹珠 vs 弹珠）。<br>- 阻尼模拟（地面摩擦力）。<br>- **手感调优**：加入随机微扰动，模拟地面不绝对平整带来的真实感。 | **高级材质物理**：<br>- 碎裂系统：累积伤害导致弹珠破碎。<br>- 材质差异：铁球（重、滑）与玻璃球（轻、涩）的物理参数差异化。 |
| **辅助系统** | **瞄准线**：显示前 0.5 米的轨迹预测，并在末端显示散布概率圆（不显示最终落点，保留不确定性）。 | **盲打模式**：<br>连胜或连击后取消辅助线，仅靠直觉和地面的尘土痕迹判断方向。 |

#### B. 玩法规则体系 (Gameplay & Rules)

| 功能模块 | MVP 阶段需求 | 后续迭代需求 (Phase 2) |
| :--- | :--- | :--- |
| **核心模式** | **街头霸王模式 (Street Sumo)**：<br>- **胜利条件**：将对方击出界外，且自己存活。<br>- **出界判定**：**球心判定法**（球体中心越过边界线即死）。<br>- **回合制**：你一杆我一杆。 | **进洞为王模式 (Tiger Hole)**：<br>- 引入“平民 vs 老虎”身份机制。<br>- 进洞升级，获得“击杀权”和“连击权”。<br>- 策略重心从“推人”转变为“占位与抢洞”。 |
| **行动机制** | **奖励回合 (Bonus Turn)**：<br>- 有效击中对手（未出界）可获得额外一次行动机会。<br>- 连击衰减：第二次奖励回合时间减半。 | **技能系统**：<br>- 不同角色的特殊技（如“大力出奇迹”、“旋转跳跃”）。 |
| **结算系统** | **基础计分**：<br>- 胜负判定。<br>- 记录击飞距离、完美压线次数。 | **赌注与收集 (The Stakes)**：<br>- 赢家可随机抽取输家的一颗弹珠（或获取碎片）。<br>- 弹珠图鉴与养成系统。 |

#### C. 视觉与美术表现 (Visuals & Art)

**整体风格：极致拟真 3D · 微缩摄影风 (Macro Realism)**

| 视觉元素 | 详细规格 |
| :--- | :--- |
| **弹珠 (Hero Asset)** | 1. **材质**：真实玻璃折射率 (IOR 1.5)，带内部 3D 构造（花瓣/猫眼）。<br>2. **瑕疵**：表面需有微磨损、划痕、气泡。<br>3. **光影**：必须实现**焦散 (Caustics)** 效果，即阳光透过玻璃球在地面投下的聚焦光斑。 |
| **场景 (Environment)** | 1. **地面**：压实的泥土地，带有细微砂砾感和干裂纹理。<br>2. **光照**：**黄金时刻 (Golden Hour)**，暖色调，低角度阳光，长阴影，丁达尔效应（尘埃光束）。 |
| **摄像机 (Camera)** | 1. **瞄准态**：手部后上方 45 度微距视角，**极浅景深 (DoF)**，聚焦于手和球，背景虚化。<br>2. **飞行态**：发射后镜头平滑跟随弹珠，模拟电影运镜。<br>3. **击中特写**：关键撞击瞬间慢动作 (Slow-mo) + 镜头冲击抖动。 |
| **手部模型** | 高精度写实模型，甚至能看清指纹和指甲盖边缘的倒刺。重点表现肌肉张力和皮肤被挤压的质感。 |

#### D. 音效设计 (Audio) - *新增补充*

虽然之前未深入讨论，但对于拟真游戏，音效至关重要。

*   **碰撞声**：根据撞击力度和材质（玻璃碰玻璃、玻璃碰铁、玻璃碰石头）播放不同的采样。必须清脆、有质感。
*   **环境音**：远处的蝉鸣、偶尔传来的车铃声、微风吹过树叶的沙沙声（营造放学后的宁静感）。
*   **UI 音效**：粉笔在黑板上写字的声音。
